Advanced Developer Portfolio

A modern, highly interactive, and fully responsive developer portfolio built using **pure HTML, CSS, and JavaScript**. This project showcases advanced frontend skills through animations, dynamic rendering, and a premium UI design without relying on frameworks.



Technologies Used

- HTML5
- CSS3 (Custom Design System)
- JavaScript (ES6+)
- Google Fonts

---

##Features Implemented

Modern UI/UX Design**
  - Dark theme with gradient effects
  - Glassmorphism & layered visuals
  - Custom design system using CSS variables

Interactive Elements**
  - Custom animated cursor
  - Smooth scroll and reveal animations
  - Rotating hero text
  - Animated counters and skill bars

Dynamic Content System**
  - Centralized configuration object for easy updates
  - Projects, skills, services, and experience rendered dynamically

Fully Responsive Layout**
  - Mobile-first design
  - Adaptive grids and flexible sections

Advanced Components**
  - Project filtering system
  - Testimonial slider with controls
  - FAQ accordion
  - Timeline-based experience section

Functional Contact Form**
  - Works via email (mailto)
  - Optional API/Formspree integration

Enhanced UX
  - Back-to-top button
  - Sticky navigation
  - Smooth navigation transitions


Purpose

This project demonstrates the ability to build **production-quality frontend applications** using vanilla technologies, focusing on performance, design, and user experience.
